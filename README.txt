Review player

Needs: Python 3.10+, ffmpeg + ffprobe in the PATH.
Install: pip install -r requirements.txt
Run: pythonw review_player.pyw [video]   (or double-click, then drop a video on the player)

Notes are saved per video in a "Reviews" folder next to the script, as vN.json plus a readable vN.txt.
Hover the "?" at the bottom right for the shortcuts.
