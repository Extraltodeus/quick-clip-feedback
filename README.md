# quick-clip-feedback
A tool to streamline comments to your favorite AI about what's wrong in a video clip during production

It looks like this:
<img width="1457" height="805" alt="image" src="https://github.com/user-attachments/assets/51012007-20ad-435e-bc77-40bcc6b73bb7" />

There is a button under the list of comments to copy them all and paste it into the AI's chat.

README.txt has a couple more infos for installation (you need FFMPEG).

## Keyboard shortcuts

| Key / action | Effect |
|---|---|
| `Space` or click on the video | Play / pause |
| `X` | Play from the start |
| `C` | Pause |
| `Left` / `Right` | 5 s back / forward |
| Wheel on the waveform | Time (down = forward) |
| `Ctrl` + wheel | 1 frame |
| `Shift` + wheel | 2 s |
| Click or drag on the waveform | Seek |
| Wheel on the video | Volume |
| Drag on the video | Move the window |
| `Ctrl+N` | New note at the current time |
| `Ctrl+Enter` or `Esc` in a note | Back to the player |
| `Enter` in a note | New line |
| `Esc` | Quit |
| Drop a video on the player | Load and play |
